Top-level `let` and `const` bindings initialized directly by class expressions need a module-local binding before their initializer is lowered. Without it, earlier module reads can bypass the existing TDZ checks: `typeof C` may return `undefined`, and `new C()` may construct before `const C = class {}` initializes. This change pre-registers and reuses a local for lexical class-expression declarations, so existing module TDZ rewriting guards early reads while the `var` path and named class-expression inner binding retain their behavior.

The regression fixture covers early reads, `typeof`, `new`, closures and methods, anonymous and named initializer references, cyclic exported access, shadowing, `var`, and post-declaration controls. A standalone helper checks the direct anonymous self-initializer ReferenceError.
