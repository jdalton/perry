Fixes #12007. Top-level `let` and `const` bindings initialized directly by class expressions need a module-local binding before their initializer is lowered. Without it, earlier module reads can bypass the existing TDZ checks: `typeof C` may return `undefined`, and `new C()` may construct before `const C = class {}` initializes. This change pre-registers and reuses a local for lexical class-expression declarations, so existing module TDZ rewriting guards early reads while the `var` path and named class-expression inner binding retain their behavior.

This is separate from #11995: that change handles exported ESM cycle sentinels and CommonJS wrapper identity, and leaves class-expression `const` TDZ out of scope.
