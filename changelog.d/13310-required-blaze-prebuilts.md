CI and development builds provision the pinned mbx, Blaze, and nightly Rust tools. Compatible Rust tests use Blaze. The full perry-runtime test harness uses mbx with Blaze disabled because Blaze currently crashes on its low-level unwind tests. The harness stays single-threaded and batched to bound memory. Development uses full unwind tables because Blaze does not support compact synchronous tables. Production compilation keeps its existing unwind configuration.
